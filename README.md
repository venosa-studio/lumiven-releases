# Lumiven

A Dynamic Island–style notch for Windows and macOS, by Venosa Studio.

Lumiven sits at the top of the screen and shows what's happening right now, such as music with synced lyrics, downloads, volume and battery. It expands into a single panel with shortcuts, controls, a mixer, notifications and search.

### macOS

Open the DMG and drag Lumiven to Applications. The app is notarized by Apple. Some features ask for permissions, such as Full Disk Access for notifications.

### Windows

Run the installer. Windows SmartScreen may show a warning because the installer has no Authenticode signature.

## Updates

Both apps check this repository and offer new versions on the notch. Windows and macOS are released separately, so their version numbers can differ.

The `macos-feed` branch holds the macOS update feed. Keep it, or installed Mac copies stop finding updates.
